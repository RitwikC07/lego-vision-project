# Vision-Guided LEGO Manipulation

An experimental robotics project exploring computer vision and vision-guided manipulation of LEGO bricks using an RGB-D camera and a robotic arm.

The project is developed incrementally, starting from basic RGB-D perception and progressing toward object detection, 3D localization, and autonomous manipulation.

## Project Goals

The main goal is to build an end-to-end pipeline that can support vision-guided object manipulation

The project will explore progressively more capable approaches to visual perception, starting with classical computer vision and eventually investigating modern deep-learning and vision-language approaches.

## Hardware

- Intel RealSense D435i RGB-D camera
- UFACTORY xArm robotic arm
- UFACTORY parallel-jaw gripper
- LEGO bricks

The RealSense camera is mounted on the robot wrist in an eye-in-hand configuration.

## Software

- Ubuntu 22.04
- ROS 2 Humble
- Python
- OpenCV
- Intel RealSense ROS 2 driver

Additional tools and models will be introduced as the project develops.

## Experiments

The project is organized as a sequence of small experiments. Each experiment is designed around a specific question and documents the method, observations, results, and lessons learned.
